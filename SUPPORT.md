# Getting help with OPEN

OPEN is in early development and run by volunteers, so replies may take a few days. Ratings are not live yet, so there are no player accounts or ratings to support.

| If you want to | Go to |
| --- | --- |
| Ask a question or talk through an idea | [GitHub Discussions](https://github.com/openpickleball/.github/discussions) |
| Report a bug or propose a change | [Open an issue](https://github.com/openpickleball/.github/issues/new/choose) |
| Share what you need as a player, club, or platform | [Send feedback](https://github.com/openpickleball/.github/issues/new/choose) |
| Propose or challenge a change to the rating spec | [Rating spec change form](https://github.com/openpickleball/.github/issues/new/choose) |
| Report a security problem | Follow the [security policy](https://github.com/openpickleball/.github/blob/main/SECURITY.md). Please don't post it publicly. |
| Report a conduct problem | Follow the [Code of Conduct](https://github.com/openpickleball/.github/blob/main/CODE_OF_CONDUCT.md#reporting-an-issue). Please don't post it publicly. |

Please keep real player names, contact details, and match histories out of public posts.
