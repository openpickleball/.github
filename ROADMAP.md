# OPEN Roadmap

This page shows OPEN's priorities across the whole project, in rough order. It has no dates because OPEN is in early development and the work depends on volunteers. Detailed plans live in each repository as they are published.

## Now

- Publish the first versioned rating spec and reference engine
- Test the engine on real match results in shadow mode, so that no one relies on its ratings yet

## Required before ratings go live

These need to be finished before anyone relies on an OPEN rating:

- Seat the governing board and hand over control of the project ([governance](https://github.com/openpickleball/.github/blob/main/GOVERNANCE.md#current-status-founding-phase))
- Publish validation results: predictive accuracy, calibration, stability, and breakdowns by player group
- Publish a privacy policy and data policy covering consent, export, and deletion
- Define the conformance requirements for showing an OPEN rating, and a policy for using the OPEN name

## Next

- Results API for platforms, clubs, and tournaments to submit matches
- Ratings and stats API so any app can show OPEN ratings, history, and stats for free
- Organizer tools to upload results, confirm starting ratings, and review flagged matches

## Later

- Public app on web, Android, and iOS with player profiles, clubs, rankings, match history, data export, and a clear explanation of how each rating was calculated

## Not planned

The [mission charter](https://github.com/openpickleball/.github/blob/main/CHARTER.md) rules out subscriptions, paid tiers, advertisements, and premium features.

## Suggest a change

To question a priority or propose a new one, [open an issue](https://github.com/openpickleball/.github/issues/new). Before proposing a feature, ask whether it makes the standard more accurate, more trusted, or easier to adopt.
